# YouTube Video Downloader

A simple application developed by **Bytetastic App Productions** for downloading YouTube videos and playlists.

1. Open the latest GitHub Release.
2. Scroll down to the **Assets** section.
3. Download the application executable.
4. Open the downloaded application.

> Always download the application from the official GitHub repository.

## Features

- **Individual Video Downloads** – Accepts individual YouTube video URLs.
- **Playlist Downloads** – Automatically detects playlist links and can download the entire playlist.
- **Automatic Playlist Detection** – No separate playlist mode required.
- **Video and Audio Extraction** – Downloads available video and audio streams.
- **Download Progress** – Displays download activity and progress in the terminal.
- **Completion Message** – Displays a confirmation message when downloading finishes.
- **Powered by yt-dlp** – Uses yt-dlp for video extraction and downloading.

## How to use?

1. Launch `YouTube Video Downloader`.
2. Copy the URL of a YouTube video or playlist you are authorised to download.
3. Paste the URL into the input field.
4. The application will begin processing the URL.
5. Wait while the video or playlist is downloaded.
6. When the download finishes, the application displays **Download Complete!**

## Playlist Downloads

The application can automatically recognise YouTube playlist URLs.

When a playlist URL is supplied, the downloader can download the entire playlist rather than just the individual video.

## Audio and Video Files

The downloader extracts available video and audio streams.

Depending on the available tools and formats, these streams may be saved separately or merged into a single file.

**FFmpeg note:** If FFmpeg is not installed, the video and audio streams may remain as separate files instead of being merged.

## Requirements

- A compatible Windows environment.
- An internet connection.
- Any additional dependencies required by the application, including FFmpeg where needed for merging audio and video.
